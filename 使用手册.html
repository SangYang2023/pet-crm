使用手册 v1.0

1. 系统简介

本系统用于管理「全国宠物行业」企业客户线索，覆盖线索查询、筛选分配、跟进留痕、数据看板全流程。无论是业务员查看自己的客户，还是管理员统筹分配，都能在一个页面内完成。

  • 线索库：所有企业客户线索的统一列表，支持搜索、多维筛选、星标重点客户。
  • 客户详情：工商信息、联系方式、线索状态、操作记录一应俱全，支持前后翻页。
  • 数据仪表盘：漏斗、业绩、省份、行业、年份分布可视化。
  • 管理员后台：批量分配 / 释放 / 改状态、按筛选批量操作、导出数据。
💡 普通业务员只能看到「未分配」或「分配给本人」的客户；管理员可见全部。仪表盘统计范围随之隔离。

2. 登录与账号

打开系统网址，输入账号密码登录。账号由部署时的环境变量配置：

环境变量格式 / 说明
CRM_USERS多账号，格式 用户名:密码,用户名2:密码2
CRM_PASSWORD单账号模式，账号固定为 team
CRM_ADMINS管理员用户名，逗号分隔，如 张三,李四
⚠️ 若部署时未配置任何账号，系统使用默认账号 admin / admin123，请尽快在部署平台的环境变量中修改！

登录后右上角显示当前账号；管理员会带 管理员 标识，并多出批量管理类按钮。

4. 查询与筛选

4.1 搜索

顶部搜索框支持按 企业名称 / 手机号 / 法人 / 信用代码 / 行业 关键词模糊搜索，输入即筛选。

4.2 条件筛选

提供以下下拉筛选（可任意组合，多个条件为「且」关系）：

筛选项说明
省份 / 城市 / 区县三级地区联动，精确到区县级
行业按经营范围行业分类
经营状态存续 / 在业 / 注销 等
线索状态待开发 / 跟进中 / 已成交 / 已流失
优先级高 / 中 / 低
业务员归属 [管理员]按负责人筛选，含「未分配」
⭐ 仅星标 [管理员]只看已标记的重点客户

4.3 重置

点击 重置 一键清除所有搜索与筛选条件。

5. 查看客户详情

点击任意一行的「查看」，右侧滑出详情抽屉，包含：

  • 联系方式：手机号、法人、信用代码等。
  • 工商信息：注册资本、成立日期、经营状态、注册地址。
  • 线索信息：线索状态、优先级、归属业务员。
  • 🕓 操作记录：每一次分配 / 释放 / 改状态的时间与操作人（见第 7 节）。

前后翻页

抽屉右上角提供 ‹ n/N › 翻页按钮，无需关闭即可在「当前筛选结果」的线索间快速切换；到首/末条时对应按钮自动变灰。

重点星标

点击 ☆ 设为星标 标记重点客户，列表与卡片中的 ☆ 会变为 ★，并可在筛选中只看星标客户。

6. 数据仪表盘

顶部的「仪表盘」展示线索汇总分析，帮助掌握整体进展：

  • 转化漏斗：待开发 → 跟进中 → 已成交 各阶段数量。
  • 业绩分布：按业务员 / 状态的统计。
  • 地理分布：省份、城市客户数量。
  • 行业 / 年份分布：客户所属行业与注册年份占比。
👁️ 权限隔离：管理员看到全部数据；普通业务员只统计「自己可见」的客户，互不干扰。

7. 管理员功能

以下功能仅管理员账号可见。普通业务员无这些按钮。

7.1 业务员归属筛选

工具栏「业务员」下拉可按负责人筛选客户，含「未分配」选项，便于查看某业务员的全部线索。

7.2 批量分配

勾选若干客户 → 点击 👥 批量分配 → 选择业务员 → 确认。所有被分配客户即归属该业务员，普通业务员将能看到。

7.3 释放（取消归属）

  • 🚫 批量释放：把已勾选的客户变为「未分配」状态。
  • 🚫 释放筛选结果(N)：一次性释放当前筛选条件下全部 N 条客户，无需逐条勾选。

7.4 按筛选分配

点击 📥 按筛选分配，将「当前筛选结果」全部客户批量指派给某业务员，适合做区域/行业集中分发。

7.5 批量改状态 / 优先级

勾选客户 → ✏ 批量改 → 选择新的线索状态或优先级（可留空）→ 应用，批量更新。

7.6 全选当前筛选

☑ 全选 一键勾选当前筛选结果的所有客户，配合上面的批量操作使用。

7.7 导出 CSV

⬇ 导出CSV 将当前列表导出为 Excel 可打开的 CSV 文件。

7.8 操作留痕

🕓 每一次分配 / 释放 / 改状态 / 停用 / 启用都会自动记录「时间 + 动作 + 操作人」，显示在客户详情的「操作记录」中，责任可追溯。

8. 移动端使用

手机浏览器打开同样可用，已做响应式适配：

  • 搜索常驻：顶部搜索框始终显示。
  • 筛选折叠：点击 🔽 筛选 (N) 展开/收起筛选面板，角标 N 表示已激活的筛选项数量。
  • 卡片视图：客户以卡片形式展示，支持「加载更多」与卡片顶部快捷排序。
  • 详情抽屉：从右侧滑出，同样支持前后翻页与星标。

9. 数据与持久化

系统数据保存在云端仓库，重新部署也不会丢：

  • 每次分配 / 改状态 / 释放等操作，都会自动把数据同步回 GitHub 的 crm-data 独立分支（不影响代码部署）。
  • 服务每次启动时自动拉取最新数据恢复，因此换实例、重新部署后数据都在。
  • 代码走 main 分支，数据走 crm-data 分支，二者分离，开启自动部署也安全。
🔄 代码更新后，部署平台会自动重新部署，浏览器刷新即可使用最新版本。

10. 常见问题

问题解决办法
登录提示账号错误确认账号密码；若用默认账号，检查是否已改为环境变量配置
看不到某些客户普通业务员仅见「未分配 / 本人」客户；联系管理员分配
筛选后想批量操作用「释放筛选结果 / 按筛选分配 / 全选」一键处理
改完代码没生效部署平台重新部署后，浏览器 Ctrl+Shift+R 强刷
想导出数据管理员点「⬇ 导出CSV」
